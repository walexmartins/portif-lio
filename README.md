# Portfólio | Walex Felipe Martins

Portfólio profissional público com estudos de caso em **desenvolvimento web, automação com WhatsApp e IA generativa**.

## Ver o site

Após habilitar o GitHub Pages em **Settings → Pages → Deploy from a branch → main → /(root)**, o endereço esperado é:
https://walexmartins.github.io/portif-lio/

> O endereço acima só estará acessível depois que o GitHub Pages for ativado e publicar o site.

## Projetos

- **Bê Modas**: plataforma de varejo e fluxos com WhatsApp Business API, webhooks, IA e automações.
- **Bê Pay**: portal em desenvolvimento para clientes, com autenticação e controle de acesso (sem integração de pagamentos).
- **Clínica Self**: site institucional responsivo com formulário de triagem para WhatsApp.

## Estrutura

- `index.html`: apresentação, projetos e diagrama geral.
- `styles.css`: identidade visual responsiva.
- `app.js`: navegação e simulação ilustrativa.
- `projetos/`: páginas de estudos de caso.
- `assets/`: diagramas vetoriais.
- `.nojekyll`: disponibilização de arquivos estáticos no Pages.

## Transparência

O desenvolvimento dos projetos foi **assistido por IA generativa**, que escreveu parte significativa do código. Minha contribuição inclui requisitos, definição de fluxos, acompanhamento da implementação, configurações de integrações, testes e ajustes. O conteúdo não expõe os repositórios comerciais privados nem informações de clientes. A simulação de mensagens é conceitual e não envia mensagens reais.
