# Publicação do portfólio
Repositório: https://github.com/walexmartins/portif-lio

Arquivos preparados na branch `main`, em pastas relativas adequadas para o GitHub Pages.

## Ativar o GitHub Pages
1. Abra https://github.com/walexmartins/portif-lio/settings/pages
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha `main` e `/(root)` e clique **Save**.
4. Confira o endereço apresentado pelo GitHub na própria tela de Pages. Após a publicação, o endereço esperado é `https://walexmartins.github.io/portif-lio/`.
5. Teste as três páginas, os diagramas, o menu e a simulação no celular.

O portfólio inclui somente arquivos estáticos. Repositórios comerciais privados devem continuar privados.
